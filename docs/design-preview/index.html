One row anatomy everywhere — thumb (eq overlay when playing) · title · version · length · state · add. Mini-player is OpenTune-style: artwork left hugged by a squared progress ring (wavy M3E outline on Android, thin arc on iOS — artwork stays square), like + resume right, swipe sideways to skip, tap/swipe-up to open. The sheet uses full-bleed artwork with a progressive bottom frost, a top radio chip, and a bottom-pinned two-line title and control cluster. Media controls go platform-native: M3E on Android (filled accent squircle play, tonal prev/next) vs liquid glass on iOS (translucent circles, real blur — OS chrome plus the deliberate artwork frost). Navbars: M3 Expressive bar vs floating glass capsule; settings is the 4th tab.

Same components, different source palettes — each card is an omarchy colors.toml mapped through the palette→ramp generator: stage/deep/raise = luminance steps off bg, hairlines = fg alphas, accent-soft = accent @~14%, text roles verbatim from the source. A contrast guard nudges any derived role under 4.5:1 toward the source, else falls back to a built-in scheme. Sources per platform: omarchy colors.toml · KDE kdeglobals · portal/OS accent (GNOME 47+, Windows, macOS) · Material You on Android.
WCO — titleBarStyle: 'hidden' + titleBarOverlay themed per scheme. The Stage column is chromeless: it runs to the top edge and macOS lights pin over its top-left — no strip of its own. World toolbar = stage toggle · centered segmented nav (squared-with-rounded indicator, sized up) · compact search field + menu at the right edge · (win/linux caption buttons overlay it). Search lives once — the field stays on every tab and simply carries the query on Explore (see the OLED frame), so there is no second field inside the body.

library — collections grid (liked · downloads · top 50 · history, play affordance on each) → your library (filter chips + sort + grid/list toggle + new-playlist card) → followed artists → recently added (shared row anatomy). Own design in the same language — not the GTK page.

Stage modes — the floating segmented control swaps the pane above the cluster: player (artwork backdrop → radio chip → meta + download/add → waveform → transport like · shuffle · prev · play · next · repeat → floating segment) / lyrics (title + sync state + scrollable lines, active in accent, estimated timing labeled honestly) / queue. The cluster — meta + actions, waveform, transport, mode segment — never leaves the surface: lyrics and queue fill the space above it instead of replacing it (see the OLED frame). The identical surface is mobile's expanded sheet — grab handle aside — and the phone's navbar hides beneath it.

icons — custom-rendered, motion by contract: eq bars on the playing thumb (live here), heart fill-in, play⇄pause morph, rotate (sync), bounce (like). Radius ladder: frame 0 · controls 8–11 (squared with rounded corners) · floating 16 · thumbs 5 · full round only where round is the meaning (switch, knob, dots) — play is a ~30% squircle, not a circle. Accent #ff8a3d = active/progress only; play = filled accent squircle (m3e) everywhere but iOS glass; liked = pink.
