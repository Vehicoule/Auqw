One row anatomy everywhere — thumb (eq overlay when playing) · title · version · length · state · add. Mini-player is OpenTune-style: artwork left hugged by a squared progress ring (wavy M3E outline on Android, thin arc on iOS — artwork stays square), like + resume right, swipe sideways to skip, tap/swipe-up to open. Media controls go platform-native: M3E on Android (filled accent squircle play, tonal prev/next) vs liquid glass on iOS (translucent circles, real blur — OS chrome, not app surface). Navbars: M3 Expressive bar vs floating glass capsule; settings is the 4th tab.

Same components, different source palettes — each card is an omarchy colors.toml mapped through the palette→ramp generator: stage/deep/raise = luminance steps off bg, hairlines = fg alphas, accent-soft = accent @~14%, text roles verbatim from the source. A contrast guard nudges any derived role under 4.5:1 toward the source, else falls back to a built-in scheme. Sources per platform: omarchy colors.toml · KDE kdeglobals · portal/OS accent (GNOME 47+, Windows, macOS) · Material You on Android.
WCO — titleBarStyle: 'hidden' + titleBarOverlay themed per scheme. Stage top strip (56 px, same line as the toolbar) centers the output-device pill; macOS lights pin to its left, the sidebar-collapse button to its right. World toolbar = search icon · centered nav tabs · menu · (win/linux caption buttons). Search is the GTK pattern: the icon expands into a field — when open it takes the toolbar's width and the nav tabs step aside (see the OLED frame), so nothing ever overlaps.

library — collections grid (liked · downloads · top 50 · history, play affordance on each) → your library (filter chips + sort + grid/list toggle + new-playlist card) → followed artists → recently added (shared row anatomy). Own design in the same language — not the GTK page.

Stage modes — the segmented switch swaps the body: player (art → meta → waveform → transport → volume) / lyrics (title + sync state + scrollable lines, active in accent, estimated timing labeled honestly) / queue. Same chrome on mobile's expanded sheet.

icons — custom-rendered, motion by contract: eq bars on the playing thumb (live here), heart fill-in, play⇄pause morph, rotate (sync), bounce (like). Radius ladder: frames 0–8 (per OS) · controls 6 · floating 12 · thumbs 5 · OS pills full. Accent #7aa2f7 = active/progress only; play = solid fg-bright on desktop; liked = pink.
